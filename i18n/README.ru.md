# MultilingualWhisper

Python CLI на базе OpenAI Whisper для генерации субтитров, дополненный точным определением и уточнением языка по каждому сегменту для видео с смешанным языком.

## ✨ Обзор

`MultilingualWhisper` — это Python CLI-пайплайн, фокусирующийся на [`vad_lang_subtitle.py`](vad_lang_subtitle.py). Он сочетает:

- Silero VAD для сегментации речи
- OpenAI Whisper для транскрипции и первоначального определения языка
- Lingua для уточнения языка на основе текста
- FFmpeg для извлечения, нормализации и обработки медиа

Основной результат — файлы субтитров `.srt` и `.json`, а также извлеченный нормализованный файл аудио `.wav`.

### Кратко

| Пункт | Детали |
|---|---|
| Основная точка входа | `vad_lang_subtitle.py` |
| Вход | Видео/аудио, совместимые с FFmpeg |
| Выход | `*.wav`, `*.srt`, `*.json` |
| Базовый поток | VAD -> Whisper -> Lingua -> уточнение |
| Типичный сценарий | Генерация субтитров для смешанного языка |

---

## 🚀 Ключевые возможности

- **Пайплайн Silero VAD -> Whisper**
  Voice Activity Detection (VAD) разделяет аудио на речевые сегменты, затем Whisper расшифровывает каждый фрагмент.

- **Точное определение языка**
  Использует [Lingua](https://github.com/pemistahl/lingua-java) вместе со встроенным детектором Whisper, чтобы помечать каждый сегмент (даже отдельные слова) кодами ISO языка (`en`, `zh`, `ja`, `ar`, `yue`, `ko`, `vi`, `es`, `fr`, ...).

- **Интеллектуальное уточнение сегментов**
  Очистка таймкодов устраняет зазоры и перекрытия. Разбиение по пунктуации делит длинные транскрипции по запятым, точкам, вопросительным знакам и т.п. Затем VAD снова выравнивает слова с блоками VAD для более плавных субтитров. Сегментация с учетом длины применяет языковые лимиты.

- **Многоязычные субтитры**
  Выводятся `.srt` и `.json`, сохраняются языковые теги по сегментам, поэтому можно применять стилизацию и фильтрацию по языку в последующих плеерах или редакторах.

- **Надежная обработка медиа**
  Аудио автоматически извлекается и нормализуется через FFmpeg, выполняются попытки исправления поврежденных контейнеров и применяется динамическая нормализация (`dynaudnorm`) для более чёткого результата транскрипции.

## 🔁 Ход пайплайна

```text
Входное медиа
  -> Извлечение + нормализация FFmpeg (.wav)
  -> Таймкоды речи от Silero VAD
  -> Расшифровка Whisper + прогноз языка
  -> Уточнение языка сегментов Lingua
  -> Объединение/разделение сегментов + очистка таймкодов
  -> Уточнение субтитров с учетом длины
  -> Вывод .srt + .json
```

Основной путь выполнения в `vad_lang_subtitle.py`:

1. Разбор CLI аргументов (`--video-path`, `--whisper-model`, `--force`).
2. Определение путей вывода по базовому имени входного файла.
3. Извлечение/нормализация аудио через FFmpeg.
4. Загрузка Silero VAD (`torch.hub`) и модели Whisper.
5. Первая транскрипция по фрагментам VAD.
6. Объединение и уточнение сегментов, затем повторная транскрипция по объединенным промежуткам.
7. Применение сокращения длины субтитров и очистки таймкодов.
8. Сохранение `.srt` и `.json`.

## ✅ Требования

- Python `3.10+` (проверялось на современных окружениях Python 3.x)
- `ffmpeg` установлен и доступен в `PATH`
- Достаточно CPU/GPU + RAM для выбранной модели Whisper (для `large` настоятельно рекомендуется GPU)
- Интернет при первом запуске для загрузки весов Whisper и артефактов Silero VAD (`torch.hub`)

Python-пакеты, используемые скриптом:

- `torch`
- `torchaudio`
- `whisper` (пакет OpenAI Whisper для Python)
- `lingua-language-detector`
- `tqdm`

Быстрые команды проверки:

```bash
python --version
ffmpeg -version
```

## 🔧 Установка

1. **Клонируйте репозиторий**

```bash
git clone git@github.com:lachlanchen/whisper_with_lang_detect.git
cd whisper_with_lang_detect
```

2. **Создайте и активируйте виртуальное окружение**

```bash
python3 -m venv venv
source venv/bin/activate
```

3. **Установите зависимости**

```bash
pip install -r requirements.txt
```

Если `requirements.txt` всё ещё отсутствует в вашей копии, установите основные зависимости вручную:

```bash
pip install torch torchaudio openai-whisper lingua-language-detector tqdm
```

И убедитесь, что FFmpeg установлен на уровне системы.

## 🛠 Использование

```bash
python vad_lang_subtitle.py \
  --video-path path/to/video.mp4 \
  --whisper-model large \
  [--force]
```

### Опции CLI

| Флаг | Алиас | Обязательно | Описание |
|---|---|---|---|
| `--video-path` | `-t` | Да | Путь к входным медиа (видео/аудио, поддерживаемые FFmpeg) |
| `--whisper-model` | — | Нет | Имя модели Whisper (по умолчанию: `large`) |
| `--force` | — | Нет | Перезапускать даже если `.wav`, `.srt` или `.json` уже существуют |

### Поведение обработки

- Имена выходных файлов формируются из базового пути входного файла.
- Для `input.mp4` выходные файлы: `input.wav` (нормализованное аудио), `input.srt` (субтитры с таймкодами) и `input.json` (метаданные, включая `start`, `end`, `lang`, `text`, при необходимости метки слов).
- Если `.srt` или `.json` уже существуют, будет пропуск, если не указан `--force`.

## ⚙️ Конфигурация

Текущие настройки в основном задаются через CLI и кодовые дефолты:

| Область конфигурации | Текущее поведение |
|---|---|
| Модель Whisper | `--whisper-model` (по умолчанию `large`) |
| Частота дискретизации обработки | Жестко задана `16000` для обработки VAD/транскрипции |
| Извлечение FFmpeg | Mono WAV, `44100 Hz`, с `dynaudnorm=f=100` |
| Детектор Lingua | Инициализирован для `ENGLISH`, `CHINESE`, `JAPANESE`, `ARABIC` в основном потоке |
| Значения фильтра на стороне Whisper | Включает `en`, `zh`, `ja`, `ar`, `yue`, `ko`, `vi`, `es`, `fr` |

Важно: списки языков в дефолтных helper-параметрах и в основной настройке детектора не полностью совпадают; в этом README отражено текущее поведение.

## 📦 Формат вывода

Инструмент пишет два субтитровых артефакта для каждого входного медиа:

- `*.srt`: стандартный текст субтитров с таймкодами `HH:MM:SS,mmm`.
- `*.json`: структурированный список субтитров с отформатированными таймкодами и языковыми метками.

Типичный вид JSON-сегмента:

```json
{
  "start": "00:00:01,234",
  "end": "00:00:03,456",
  "lang": "en",
  "text": "Hello world",
  "words": [
    {
      "word": " Hello",
      "start": 1234,
      "end": 1678,
      "probability": 0.98
    }
  ]
}
```

Примечания:

- `start`/`end` сериализуются в JSON как строки в формате SRT.
- `words` может присутствовать в зависимости от этапа обработки/уточнения сегмента.
- Значение `lang` равное `und` может появляться для неуверенных языковых фрагментов.

## 🧭 Заметки по разработке

- Канонический активный скрипт: `vad_lang_subtitle.py`.
- Исторические файлы (`*.old`, `*.shorterlength*`, `archived/`) полезны для справки, но выглядят неканоничными.
- На данный момент отсутствует инфраструктура проекта (`pyproject.toml`, `setup.py`) и подключенный CI/набор тестов.
- `data/` содержит большие примеры медиа и сгенерированные артефакты; учитывайте размер репозитория и использование диска при экспериментах.
- `clean_subtitles_dict()` есть в коде, но в текущем основном конвейере не вызывается.
- `--force` — текущий механизм для гарантированной перегенерации выходов во время итеративной настройки.

Рекомендуемый локальный цикл разработки:

```bash
python vad_lang_subtitle.py -t data/<your_media>.mp4 --whisper-model small --force
```

Используйте более маленькую модель (`tiny`/`base`/`small`) на этапе итераций, затем переходите на `large` для итогового качества.

## 🩺 Устранение неполадок

| Симптом | Что делать |
|---|---|
| `ffmpeg: command not found` | Установите FFmpeg и проверьте через `ffmpeg -version`. |
| Первый запуск очень медленный или кажется зависшим | Первичная загрузка моделей (Whisper + Silero) может занять время; повторные запуски проходят быстрее. |
| Ошибки CUDA / GPU | Попробуйте fallback на CPU, используя более легкую модель Whisper (`small`, `base`, `tiny`), и проверьте соответствующую сборку PyTorch для вашей среды. |
| Выходные файлы не пересобираются | Используйте `--force`, чтобы перезаписать уже существующие производные файлы. |
| `pip install -r requirements.txt` падает, потому что файл не найден | Используйте ручную установку зависимостей, как показано в разделе Установка. |
| Неверная метка языка на коротких сегментах | Такое возможно на очень коротких/шумных отрезках; текущая логика сочетает Whisper и Lingua, но у нее есть граничные случаи. |
| Пустой или почти пустой результат субтитров | Убедитесь, что в исходном материале есть речь, проверьте извлеченный `.wav`, затем повторите с `--force` после проверки извлечения FFmpeg. |
| Неожиданная смена языка между соседними строками | Такое может происходить на очень коротких сегментах; выполните последующее объединение по языку и минимальной длительности во внешних инструментах. |

## ⚠️ Известные ограничения и предположения

- Манифест зависимостей не зафиксирован (`requirements.txt`, `pyproject.toml` и `setup.py` отсутствуют в корне репозитория на момент написания).
- Лицензия указана в README как MIT, но отдельный файл `LICENSE` пока не присутствует.
- Lingua явно инициализируется с `EN/ZH/JA/AR` в основном потоке, а helper defaults включают больше кодов языков-кандидатов.
- Автоматические тесты/бенчмарки пока не добавлены, поэтому валидация в основном ручная.
- Исторические скрипты расположены в корне и в `archived/`; для активной работы следует считать основным только `vad_lang_subtitle.py`, если только вы не проводите эксперимент.
